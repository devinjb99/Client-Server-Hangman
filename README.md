# Client-Server-Hangman
This project is a Python-based client–server chat application that uses TCP sockets to allow two programs to communicate over a network connection. In addition to basic message exchange, the server can launch an interactive Hangman game.

## How it works
First start the server.py, then start the client.py then follow the termial based directions.
You will then playing hangman using TCP sockets and communicating over a network connection.
